Quick guide

N · Place points. E · Place an EOL point (diamond marker).

C · Draw the central pull from box to end; click regular points to connect and continue. L · Click the trunk, optional waypoints, then a point. EOL makes a one-way final run and trims leftover trunk. Loop order updates from the far end back to the box.

T · Tap to start, then tap each turn. Each tap adds one straight leg. Enter or double-click finishes. Esc cancels.

Arrow badges show trunk / step, in the order you clicked. Reverse runs use the opposite side.

D · Dotted floor link: click two points to mark an inter-floor cable transition. Repeat for more transitions.

Shift · Choose the other drawing axis.

V · Select & drag. Blue handles edit route waypoints. Attached endpoints follow devices.

Scroll to pan. Ctrl/⌘ + wheel to zoom. Save a project to carry the PDF and all editable markings together.
